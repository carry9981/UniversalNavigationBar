# 配置指南

本文说明如何**只通过配置文件**增删导航条条目、脚本等内容，无需修改源代码。

---

## 一、配置文件位置（重要）

程序按以下优先级查找 `config.json`：

| 优先级 | 位置 | 说明 |
|--------|------|------|
| 1 | 环境变量 `UNB_CONFIG_DIR` 指定的目录 | 高级用法，一般不用 |
| 2 | **程序根目录**下的 `config.json` | **便携模式（推荐）**：只要该文件存在就用它 |
| 3 | `%APPDATA%\UniversalNavBar\config.json` | 未启用便携模式时的默认位置 |

> **结论**：直接编辑程序根目录里的 `config.json`（本仓库根目录那个），
> 然后重启程序，或在系统托盘点「🔄 重新加载配置」即可生效。**无需改动任何源码。**

可用系统托盘菜单快速打开：

- 「⚙ 打开设置…」→ 用默认编辑器打开当前生效的 `config.json`
- 「📂 打开配置文件夹」→ 打开配置文件所在目录

## 二、条目的基本结构

导航条的每个按钮对应 `items` 数组里的一个对象：

```json
{
  "id": "my_item_1",
  "name": "显示名称",
  "icon": "📋",
  "type": "hotkey",
  "enabled": true,
  "order": 0,
  "config": { }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 否 | 唯一标识；留空/重复不影响显示，建议唯一 |
| `name` | string | **是** | 显示名称 |
| `icon` | string | 否 | Emoji 图标，如 `📋` `🔍` `🎤` |
| `type` | string | **是** | `hotkey` / `text` / `script` |
| `enabled` | bool | 否 | 是否启用，默认 `true` |
| `order` | int | 否 | 排序权重，越小越靠前 |
| `config` | object | **是** | 类型专属配置，见下 |

---

## 三、三种类型

### 1. hotkey —— 模拟快捷键

```json
{
  "id": "builtin_voice_input",
  "name": "语音输入",
  "icon": "🎤",
  "type": "hotkey",
  "enabled": true,
  "order": 4,
  "config": {
    "keys": ["ctrl", "f2"],
    "delay_ms": 50
  }
}
```

- `keys`：按键序列，修饰键在前。支持：`ctrl` `alt` `shift` `win`、字母 `a-z`、数字 `0-9`、`f1-f12`、`enter` `space` `tab` `escape` `backspace` `delete` `up` `down` `left` `right` 等。
- `delay_ms`：按下/抬起之间的间隔（毫秒）。

### 2. text —— 输入预设文本

```json
{
  "id": "my_greeting",
  "name": "问候语",
  "icon": "👋",
  "type": "text",
  "enabled": true,
  "order": 10,
  "config": {
    "content": "您好，请问有什么可以帮助您的？",
    "mode": "type",
    "delay_ms": 10,
    "variables": true
  }
}
```

- `content`：要输入的内容，支持变量占位符（见第五节）。
- `mode`：`type`（逐字符输入）或 `paste`（剪贴板粘贴，适合长文本/中文）。
- `delay_ms`：`type` 模式字符间隔。
- `variables`：是否启用变量替换。

### 3. script —— 运行 Python 脚本

```json
{
  "id": "my_script",
  "name": "我的脚本",
  "icon": "🚀",
  "type": "script",
  "enabled": true,
  "order": 20,
  "config": {
    "script": "my_script.py",
    "args": ["--text", "{selected_text}"],
    "timeout_sec": 30,
    "run_async": true
  }
}
```

- `script`：`plugins/` 目录下的脚本文件名，或绝对路径。
- `args`：命令行参数数组，支持变量占位符。
- `timeout_sec`：超时秒数，`0` 表示不限。
- `run_async`：是否异步执行（不阻塞界面）。

> 脚本的编写与调用详见 **[插件开发指南](插件开发指南.md)**。

## 四、增 / 删 / 改条目

- **增加**：在 `items` 数组里追加一个对象。
- **删除**：从 `items` 数组里移除对应对象。
- **临时禁用**：把 `enabled` 改为 `false`（不显示但保留配置）。
- **调整顺序**：修改 `order`，数值越小越靠前；相同则按 `id` 排序。
- **改图标/名称**：修改 `icon` / `name`。

改完后：

1. 托盘 →「🔄 重新加载配置」，或
2. 重启程序。

也可以完全用鼠标操作：托盘 →「📝 管理条目…」，在图形界面里添加/编辑/删除/排序，点「💾 保存更改」。

## 五、变量占位符

用于 `text.content` 和 `script.args`：

| 占位符 | 替换为 |
|--------|--------|
| `{selected_text}` | 触发时选中的文本 |
| `{clipboard}` | 当前剪贴板内容 |
| `{date}` | 当前日期 `YYYY-MM-DD` |
| `{time}` | 当前时间 `HH:MM:SS` |
| `{newline}` | 换行符 |
| `{mouse_x}` / `{mouse_y}` | 触发时的鼠标坐标 |
| `{active_window}` | 活动窗口标题 |
| `{trigger_time}` | 触发时间戳 |
| `{item_id}` / `{item_name}` | 条目 ID / 名称 |

## 六、其它配置项

```json
{
  "trigger": {
    "text_select":   { "enabled": true, "min_distance_px": 15, "max_duration_sec": 2.0 },
    "left_click_hold": { "enabled": true, "hold_duration_sec": 0.5, "move_tolerance_px": 6 }
  },
  "text_getter": {
    "method": "uiautomation",
    "fallback_to_clipboard": true,
    "clipboard_restore": true,
    "cache_duration_ms": 500
  },
  "ui": {
    "theme": "dark",
    "opacity": 0.92,
    "border_radius_px": 10,
    "font_family": "Microsoft YaHei, sans-serif",
    "font_size_px": 13,
    "item_padding_px": 8,
    "max_width_px": 400,
    "position_offset_px": 15,
    "shadow": true
  },
  "general": {
    "auto_start": true
  }
}
```

| 配置项 | 说明 |
|--------|------|
| `trigger.text_select` | 框选文本触发 |
| `trigger.left_click_hold` | 左键长按触发 |
| `text_getter.method` | 文本获取方式（`uiautomation` / `clipboard`） |
| `ui.*` | 主题、透明度、字体、宽度、偏移等外观 |
| `general.auto_start` | 开机自启动 |

## 七、常见问题

- **改了 config.json 没反应？**
  确认你改的是「当前生效」的那份。托盘 →「⚙ 打开设置…」打开的就是生效文件。
  若程序目录存在 `config.json`，则以它为准（便携模式）。
- **中文/Emoji 显示为乱码？**
  请将 `config.json` 保存为 **UTF-8** 编码。
- **条目点击没反应？**
  检查 `type` 与 `config` 是否匹配，保存后可用托盘「重新加载配置」。
