# 插件开发指南

Universal Navigation Bar（UNB）的插件就是一个 **Python 脚本**。把它放进 `plugins/` 目录，
再在 `config.json` 里加一条 `script` 类型的条目，就能从导航条一键调用。

> 无需修改 UNB 源码。**添加/删除插件完全通过配置文件完成。**

---

## 一、最小示例

### 1. 写脚本 `plugins/hello.py`

```python
#!/usr/bin/env python3
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import get_selected_text, has_selected_text

def main():
    if has_selected_text():
        print(f"选中文本：{get_selected_text()}")
    else:
        print("没有选中文本")

if __name__ == "__main__":
    main()
```

### 2. 在 `config.json` 的 `items` 里加一条

```json
{
  "id": "my_hello",
  "name": "Hello",
  "icon": "🚀",
  "type": "script",
  "enabled": true,
  "order": 20,
  "config": {
    "script": "hello.py",
    "args": [],
    "timeout_sec": 30,
    "run_async": true
  }
}
```

### 3. 生效

托盘 →「🔄 重新加载配置」，或重启程序。点击导航条上的「🚀 Hello」即可运行。

---

## 二、`script` 条目配置项

| 字段 | 必填 | 说明 |
|------|------|------|
| `script` | 是 | 脚本文件名（相对 `plugins/`），或绝对路径 |
| `args` | 否 | 命令行参数数组，支持变量占位符 |
| `timeout_sec` | 否 | 超时秒数，`0` 表示不限；默认 30 |
| `run_async` | 否 | `true` 异步执行（不阻塞界面），`false` 同步等待 |

示例（带参数）：

```json
"config": {
  "script": "search_web.py",
  "args": ["--text", "{selected_text}", "--x", "{mouse_x}", "--y", "{mouse_y}"],
  "timeout_sec": 10,
  "run_async": true
}
```

## 三、三种获取上下文的方式

脚本可以通过以下任一方式拿到「选中文本 / 剪贴板 / 鼠标位置」等上下文。
三种方式**同时可用**，任选其一或混用。

### 方式一：`unb_utils` 模块（Python 脚本推荐）

`plugins/unb_utils.py` 由 UNB 提供，随插件目录一起分发。

```python
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import (
    get_selected_text, get_clipboard, get_mouse_position,
    get_active_window, get_trigger_time, get_item_id, get_item_name,
    get_config_dir, get_plugin_dir, get_context, has_selected_text,
)
```

| 函数 | 返回 |
|------|------|
| `get_selected_text()` | 选中文本（可能为空串） |
| `get_clipboard()` | 剪贴板内容 |
| `get_mouse_position()` | `(x, y)` 元组 |
| `get_active_window()` | 活动窗口标题 |
| `get_trigger_time()` | 触发时间字符串 |
| `get_item_id()` / `get_item_name()` | 条目 ID / 名称 |
| `get_config_dir()` / `get_plugin_dir()` | 配置目录 / 插件目录 |
| `get_context()` | 上述全部组成的字典 |
| `has_selected_text()` | 是否有非空选中文本 |

### 方式二：环境变量

UNB 调用脚本时会设置以下环境变量（即使为空也会设置）：

| 环境变量 | 说明 |
|----------|------|
| `UNB_SELECTED_TEXT` | 选中的文本 |
| `UNB_CLIPBOARD` | 剪贴板内容 |
| `UNB_MOUSE_X` / `UNB_MOUSE_Y` | 鼠标位置 |
| `UNB_ACTIVE_WINDOW` | 活动窗口标题 |
| `UNB_TRIGGER_TIME` | 触发时间 |
| `UNB_ITEM_ID` / `UNB_ITEM_NAME` | 条目 ID / 名称 |
| `UNB_CONFIG_DIR` | 配置目录 |
| `UNB_PLUGIN_DIR` | 插件目录 |

```python
import os
text = os.environ.get("UNB_SELECTED_TEXT", "")
x = int(os.environ.get("UNB_MOUSE_X", "0"))
```

> 非 Python 语言（如批处理、PowerShell、Node）也可用环境变量方式。

### 方式三：命令行参数

在 `args` 中使用变量占位符，UNB 会替换后作为参数传入：

```json
"args": ["--text", "{selected_text}", "--x", "{mouse_x}"]
```

实际执行：`python plugins/xxx.py --text "用户选中的内容" --x 500`

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument("--text", default="")
parser.add_argument("--x", type=int, default=0)
args = parser.parse_args()
```

## 四、变量占位符完整列表

可用于 `script.args` 与 `text.content`：

| 占位符 | 替换为 |
|--------|--------|
| `{selected_text}` | 触发时选中的文本 |
| `{clipboard}` | 当前剪贴板内容 |
| `{date}` | 当前日期 `YYYY-MM-DD` |
| `{time}` | 当前时间 `HH:MM:SS` |
| `{newline}` | 换行符 |
| `{mouse_x}` / `{mouse_y}` | 触发时鼠标坐标 |
| `{active_window}` | 活动窗口标题 |
| `{trigger_time}` | 触发时间戳 |
| `{item_id}` / `{item_name}` | 条目 ID / 名称 |

未知占位符会替换为空字符串；值为空时也替换为空字符串。

## 五、执行细节

| 项目 | 说明 |
|------|------|
| 解释器 | 开发运行时用当前 Python；**打包后**回退到系统 `python`（可用环境变量 `UNB_PYTHON` 指定解释器） |
| 工作目录 | `plugins/` 目录，便于脚本用相对路径读取资源 |
| 参数 | `script` 解析为绝对路径后作为第一个参数，其后是替换后的 `args` |
| 环境变量 | 继承 UNB 进程环境，并注入上表 `UNB_*` 变量 |
| 超时 | 超过 `timeout_sec` 会被终止 |
| 输出 | 继承 UNB 进程的标准输出；开发模式下 `print` 会显示在控制台 |
| 异步 | `run_async: true` 时在后台线程运行，不阻塞界面 |

> 打包为 exe 后，运行 `script` 插件需要系统已安装 Python。若使用便携版 Python，
> 可设置环境变量 `UNB_PYTHON=C:\path\to\python.exe`。

## 六、完整示例

### 示例 1：搜索选中文本

```python
#!/usr/bin/env python3
"""未选中文本时打开搜索引擎首页。"""
import os, sys, urllib.parse, webbrowser
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import get_selected_text, has_selected_text

def main():
    if has_selected_text():
        url = "https://www.google.com/search?q=" + urllib.parse.quote(get_selected_text())
    else:
        url = "https://www.google.com"
    webbrowser.open(url)

if __name__ == "__main__":
    main()
```

### 示例 2：选中文本转大写并替换粘贴

```python
#!/usr/bin/env python3
"""把选中文本转为大写，写入剪贴板并 Ctrl+V 粘贴。"""
import os, sys, time
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import get_selected_text
import pyperclip
from pynput.keyboard import Controller, Key

def main():
    text = get_selected_text()
    if not text:
        print("未选中文本")
        return
    pyperclip.copy(text.upper())
    kb = Controller()
    with kb.pressed(Key.ctrl):
        kb.press("v"); kb.release("v")

if __name__ == "__main__":
    main()
```

### 示例 3：插入当前日期（不依赖选中文本）

```python
#!/usr/bin/env python3
import os, sys
from datetime import datetime
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import get_item_name

def main():
    name = get_item_name()
    now = datetime.now()
    if "日期" in name:
        result = now.strftime("%Y-%m-%d")
    elif "时间" in name:
        result = now.strftime("%H:%M:%S")
    else:
        result = now.strftime("%Y-%m-%d %H:%M:%S")
    print(result)

if __name__ == "__main__":
    main()
```

### 示例 4：读取上下文并写入日志

```python
#!/usr/bin/env python3
import os, sys, json
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from unb_utils import get_context, get_plugin_dir

def main():
    log = os.path.join(get_plugin_dir(), "unb_plugin.log")
    with open(log, "a", encoding="utf-8") as f:
        f.write(json.dumps(get_context(), ensure_ascii=False) + "\n")

if __name__ == "__main__":
    main()
```

### 示例 5：调用外部命令

```python
#!/usr/bin/env python3
import subprocess
# 例如打开计算器
subprocess.Popen("calc.exe")
```

## 七、调试技巧

1. **脱离 UNB 单独运行**：直接 `python plugins/xxx.py`，需要上下文时手动设置环境变量：

   ```bat
   set UNB_SELECTED_TEXT=hello
   set UNB_MOUSE_X=100
   python plugins\xxx.py
   ```

2. **打印调试**：开发模式（`python -m src.main`）下脚本的 `print` 会出现在控制台。
   打包成无控制台的 exe 后，建议把日志写入文件（见示例 4）。

3. **查看实际命令**：临时把 `run_async` 设为 `false`，便于观察同步输出。

4. **超时排查**：脚本卡住时会被 `timeout_sec` 终止，适当调大或设为 `0`。

---

## 八、注意事项与约定

1. **选中文本可能为空**（例如左键长按触发、目标软件不支持 UIA），脚本务必做空值判断。
2. 不要假设工作目录一定是某个位置，用 `get_plugin_dir()` / `get_config_dir()` 获取绝对路径。
3. 依赖的第三方库需自行安装到所用 Python 环境（`pip install xxx`）。
4. 脚本名建议使用英文，避免中文路径带来的兼容问题。
5. `unb_utils.py` 由 UNB 提供，请勿删除；可随插件目录一起分发。
6. 脚本在独立进程中运行，崩溃不会影响 UNB 主程序。

---

## 九、常见问题

| 问题 | 原因 / 解决 |
|------|-------------|
| 点击条目没反应 | 检查 `script` 文件名是否正确、是否在 `plugins/`；查看控制台/日志 |
| 提示找不到 Python | 打包版需要系统安装 Python，或设置 `UNB_PYTHON` |
| `import unb_utils` 失败 | 在脚本开头把脚本所在目录加入 `sys.path`（见示例） |
| 中文乱码 | 脚本文件保存为 UTF-8；输出到文件时显式 `encoding="utf-8"` |
| 拿不到选中文本 | 目标软件可能不支持 UI Automation；确认触发时确实有选中文本 |
